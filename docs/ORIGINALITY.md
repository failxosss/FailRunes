# Originality

FailRunes implements the **publicly documented gameplay structure and functionality** described in the
brief (XP-priced rune tomes, common/rare/legendary/mythical tiers, special zone/crate/boss/seasonal pools,
an Infuser-style GUI, success/fail/critical-fail application, Lucky Gems, incineration, cleansing, a
detector/identifier flow, cooldown popups, active-rune snapshotting, etc.) using entirely original:

- Java source code and architecture
- rune IDs, names, descriptions and numeric balancing
- GUI layouts, textures/materials (vanilla fallbacks; ItemsAdder IDs are placeholders you fill in)
- plugin identity: **FailRunes** by **Failxos**, with no reference to any other server, network or brand

No proprietary source code, textures, GUI artwork, logos or protected descriptions were copied. Where a
named mechanic's public behavior is documented (e.g. "Scattershot fires extra arrows"), this plugin
reproduces that *behavior* with original code and content, per requirement #84/#85 of the brief — it does
not claim to reproduce anyone's exact proprietary numbers or implementation.
